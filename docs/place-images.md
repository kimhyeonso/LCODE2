# 일정 장소 사진 보완

- 기존 장소 사진 연결: 일정 항목 417개
- 검색으로 추가한 이미지: 31개 (여러 일정의 같은 장소에서 재사용)
- 전체 장소 일정 항목: 937개, 사진 연결 완료: 877개
- 남은 60개: 자유 식사·체크인·렌터카·셔틀 집합·선택형 방문 등 특정 장소가 확정되지 않은 항목, 하얼빈 호텔 1개 포함
- 하얼빈 Ibis Central Avenue Airport Bus Station: 장소에 맞는 사진을 찾았지만 원본 서버가 HTTP 403으로 다운로드를 거부하여 미반영. 다른 Ibis 지점 사진으로 대체하지 않음.

`src/data/place-image-sources.json`에 검색 URL, 원본 페이지, 다운로드 URL, 저작자/게시자, 라이선스를 기록했다. 22개는 Wikimedia의 라이선스 또는 퍼블릭 도메인 정보를 확인했다. 나머지 9개는 숙소·관광·상업 사이트의 사진이며 별도의 재사용 허가는 확인하지 않았다(`reusePermissionVerified: false`). 출처 표시는 재사용 허가를 의미하지 않는다.

일정 상세의 ‘사진 출처’에서 이번에 추가한 사진의 출처를 확인할 수 있다. 저장된 일정의 빈 이미지도 도시와 장소명이 일치하면 보완된 카탈로그 사진을 사용한다. 기존 사용자 지정 사진은 유지한다.

검증: 전체 빌드 성공, 신규 이미지 31개 디코딩 성공, 리믹스 테스트 8개 통과. 브라우저 화면의 직접 검증은 수행하지 못했다.

남은 항목의 전체 목록: `docs/place-image-audit.json`.
